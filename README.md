Autonomous Delivery Cart System

A final year graduation project demonstrating a complete end-to-end autonomous delivery solution using AWS Cloud, IoT, and a cross-platform mobile application.

🚀 Project Overview

This project provides a proof-of-concept for an autonomous, last-mile delivery service designed for closed environments like residential compounds, hotels, or university campuses. It features a customer-facing mobile app for placing orders, a web portal for vendors to manage deliveries, a cloud backend for orchestration, and a physical smart cart for autonomous navigation.

✨ Key Features

Customer Mobile App: Browse items, place orders, and track deliveries in real-time.

Vendor Web Portal: Manage inventory, confirm incoming orders, and dispatch carts.

Manager Dashboard: View system-wide analytics, monitor cart status, and manage users.

Autonomous Cart: Navigate to delivery locations, receive commands, and allow secure package retrieval via OTP.

Real-Time Communication: Secure, low-latency communication between all system components via AWS IoT Core and APIs.

🛠️ Technology Stack

Cloud & Backend: AWS (CDK, Lambda, API Gateway, Cognito, RDS, DynamoDB, IoT Core)

Mobile App: Flutter / React Native

Web App: React / Vue.js

Cart Firmware: Python, ROS (Robot Operating System) on NVIDIA Jetson

Databases: PostgreSQL (RDS), DynamoDB
